## 💼 Projetos em Destaque

### 1. **🎨 [Gerador de Memes](https://github.com/fabioovila/meme_generator)** 
**Projeto Final CS50P (Harvard University)**

Uma aplicação CLI profissional para automação de criação de memes com template management inteligente.

**Destaques Técnicos:**
- 🖼️ Processamento de imagens com **Pillow (PIL)** - renderização de texto, manipulação de coordenadas
- 🌐 Integração HTTP com **Requests** - download seguro de templates com validação de Content-Type
- ✅ **Arquitetura testável** - Separação de concerns para testes automatizados com pytest
- 📦 Persistência de dados com **JSON** - Configuração leve e versionável
- 🔒 **Validação robusta** - URL validation com `validator-collection`, tratamento de exceções
- 🧪 **Testes Unitários** - Suite completa de testes cobrindo funções críticas

**Stack:** Python 3 | Pillow | Requests | pytest | JSON | CLI Design Patterns  
**Habilidades demonstradas:** Image Processing | Web Requests | File I/O | Error Handling | TDD | Software Architecture
